# AGENTS.md

Guidance for agents working in **conduit** (`early-effect/conduit`). Scala 3 / ZIO 2 unidirectional state management (Redux-shaped loop, lenses, typed effects). Published to Maven Central as `rocks.earlyeffect::conduit`.

## Layout

| Path | Role |
| --- | --- |
| [`core/`](core/) | The published library. `sbt-projectmatrix`: JVM, Scala.js, Native. |
| [`example/`](example/) | Runnable JVM demos. `publish / skip`, `test / skip`. |
| [`docs/`](docs/) | Specular site (DocSpecs + JS client). Not published. |
| [`.github/workflows/ci.yml`](.github/workflows/ci.yml) | Generated by zipx. Do not hand-edit. |

Root aggregates `core`, `example`, and `docs` (JVM + JS) and skips its own `publish` / `test`.

**Do not add ascent (or `ascent-conduit`) to `core`.** Ascent is a **docs-only** Maven dependency so the published artifact does not depend on a library that already depends on conduit.

## Commands

sbt 2: `test` is `testQuick` and can skip. Use **`testFull`** for proof. Prefer Metals `compile-file` then Metals `test` while iterating. Join Metals' BSP with `sbt --no-server`; do not spawn a second `--detach-stdio` server.

```bash
sbt compile                          # all platforms
sbt testFull                         # core specs + docs DocSpecs (not example)
sbt "core/testFull"                  # library only
sbt "testOnly conduit.LensSpec"      # one suite
sbt "example/run"                    # JVM demo
sbt docs/specularSite                # build the docs site (links docsJS)
sbt docsPreview                      # ~docs/specularPreview
sbt zipxWorkflowGenerate             # after zipx settings / graph changes
sbt zipxWorkflowCheck                # CI drift gate
```

JDK **25** in CI (`zipxJavaVersion`). Scalafmt is the PR formatter (Metals is edit-time only): `sbt scalafmtCheckAll` before push.

## Architecture

Dispatch is **enqueue then drain**. `c(actions*)` only offers onto an unbounded queue. Nothing runs until `c.run()` (drain until empty) or `c.run(false)` (until `Done`). Live UI examples must keep a dispatch loop running (`forkScoped` of `run(false)`), not only enqueue.

```
c(action) → Queue → run() → handler → ActionResult → Ref
         ↘ if FastEq says the model changed → each Listener (FastEq on its slice)
         ↘ ActionResult.next follow-ups dispatch immediately (nested, not re-queued)
```

`Subscribe` as a `ConduitOp` is for handler follow-ups. `c.subscribe(path)(cb)` registers on the `Ref` immediately and does not wait for `run()`.

| Type | File | Notes |
| --- | --- | --- |
| `Conduit[M, E]` | [`Conduit.scala`](core/src/main/scala/conduit/Conduit.scala) | `Ref[ConduitState]` + queue. `[M: FastEq]` at `apply` / `make`. Dispatch-level FastEq can skip **all** listeners. `unsafe` runs against `Runtime.default`. |
| `Dispatchable` / `AppAction` / `ConduitOp` | [`Dispatchable.scala`](core/src/main/scala/conduit/Dispatchable.scala) | There is no `AppAction.scala`. Prefer `Action` (`AppAction[Any, Nothing]`) or `ActionE[E]`. Sentinels: `NoAction`, `Done`. |
| `ActionHandler[M, V, E]` | [`ActionHandler.scala`](core/src/main/scala/conduit/ActionHandler.scala) | Partial function to `IO[E, ActionResult[M, E]]`, focused by a lens. `>>` = orElse, `++` = fold (OR dirty). DSL: `handle`, `update`, `updated`, `focus`, `noChange`, `effectOnly`. |
| `ActionResult[M, E]` | [`ActionResult.scala`](core/src/main/scala/conduit/ActionResult.scala) | `newModel`, `next`, `dirty`. |
| `Lens` / `Optics` | [`Lens.scala`](core/src/main/scala/conduit/Lens.scala), [`Optics.scala`](core/src/main/scala/conduit/Optics.scala) | `derives Optics`; `Optics[M](_.field.nested)`. Compose with `>>`. Macro is field-path only. |
| `CollectionLens` | [`CollectionLens.scala`](core/src/main/scala/conduit/CollectionLens.scala) | `at` / `atVector` / `key` → `Option[V]` (runtime index/key; the macro cannot do this). |
| `Iso` | [`Iso.scala`](core/src/main/scala/conduit/Iso.scala) | `imap` / `xmap` on a lens. Lawfulness is the caller's contract. |
| `Listener[M, E, S]` | [`Listener.scala`](core/src/main/scala/conduit/Listener.scala) | Last-value cache; `[S: FastEq]` at construction, used before the callback. |
| `FastEq[-A]` | [`FastEq.scala`](core/src/main/scala/conduit/FastEq.scala) | Optional. Fallback `==` via a low-priority `given`. Factories: `fromEquals`, `instance`, `withReferenceEquality`, `fromVersion`, `fromHash`, `withDirtyFlag`, `derived`. |

Prefer a new handler combinator, lens helper, FastEq factory, or `ConduitOp` over changing the dispatch loop.

`derives Optics` models used in Specular `example` / `exampleIO` blocks must be **object-level**. Local classes inside those macros do not typecheck.

## Docs

Specular DocSpecs under [`docs/src/test/scala/conduit/docs/`](docs/src/test/scala/conduit/docs/). JVM builds the site; `docsJS` remounts `.interactive` examples (`ClientMain` + `ExampleRegistry`). Diagrams: mermaid fences and `specular.mermoid.Mermoid` (not pasted SVG).

- Shared `DocSpec` pages (JS-safe) + thin JVM `DocSpecSuite` wrappers.
- After adding a `.interactive` example, it must appear in `ClientMain`'s page list; `InteractiveContractSpec` guards drift.
- `specularJsLink` writes `target/specular-client-js.path`; `BuildSite.afterBuild` copies `assets/client.js`.
- Do not revive marklit or commit `docs-generated/`.

## Cross-platform (`core` only)

Must compile on JVM, JS, and Native. No `java.*` outside what `scala-java-time` covers, no reflection, no `Thread`, no blocking I/O.

## CI and publishing

zipx Aggregate: parallel `fmt` / `workflow-check` / `advisories` / `test` (`testFull`), then tag-gated `ZipxCentral.release` and `ZipxDocs.pages()`. Fork-gated to `early-effect/conduit`.

Capability or graph change → `sbt zipxWorkflowGenerate` and commit `.github/workflows/ci.yml` plus `.github/actions/zipx-sbt-setup/`. CI fails on drift via `zipxWorkflowCheck`.

Publishing is CI-only (`usePgpKeyHex` from `PGP_KEY_HEX`; sentinel `MISSING_KEY_HEX` locally). Native Central: `localStaging` / `publishSigned` / `sonaRelease`. Do not cut tags or push `main` from an agent unless asked.

## Conventions

- Scala 3 only: `enum`, `given`, `derives`, inline, optional braces. Scalafmt: max 120, `align.preset = more`, convert to new syntax.
- `-Wunused:all`: no unused imports or locals.
- Immutable models; updates through lenses.
- Typed `IO[E, A]`; `.widen` when composing handlers with different `E`.
- Tests: ZIO Test `ZIOSpecDefault` in [`core/src/test/scala/conduit/`](core/src/test/scala/conduit/). DocSpecs are tests too.
- Keep [`example/`](example/) building when you change the public API.
- No AI attribution in commits or PR text.
